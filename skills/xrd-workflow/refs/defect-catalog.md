# 附录 A：XRD 精修缺陷总表（14 类）

> **归属**：`xrd-workflow` §6「复杂情况检查表」的**附录 A**（唯一家；其他 skill 只写"见 §6 附录 A"）。
> **性质**：**只读底表**，我方维护；**AI 不得往本表加行**。
> **用法**：AI 参照本表**为每个样品建自己的检查表**（第二层 `defect_table.json`，10 字段，见 §6.9）。
> **引用方式**：§6 检查表的**缺陷部分**用一个**带独立表头表尾的块**引用本表并**引导 AI 读取**（块文本见 §6）。
> **表外情形倒回主表**：遇到本表**没有**的缺陷或异常 ⇒ **不扩写本表**，倒回 §6 **主表**按
> **数值性 / 模型性 / 结构性 / 数据性**四分类逐级升级处置；确要试表外新假设 ⇒ 写进**每样品检查表**
> （`source=unknown`、`id` 自拟 `X-01`…），**不动本表**。
> **出处规则**：**缺陷类型这类经验知识不强制出处**；但凡引用**别人的具体数值**（几何值、参照 R、文献占位/键长）**必须标出来源**。

**字段**：`id` / `family` / `defect` / `structural_form`（模型里怎么写）/ `xrd_signature`（XRD 可观测特征）/
`judge`（判定手段）/ `params_backend`（参数 + 允许后端）/ `pitfall`（常见误判）＝ **8 必需**；
`reachability`（**可达性标记：起点依赖** —— 标了的条目必须"回到 §6.3 Ⅲ ①②确认 CIF 筛选已执行"；目前 **D-06 / D-09** 带此标记）/
`example` / `source` ＝ **可选**。机器骨架：`refs/defect_catalog.json`。

**⚠ 本表只收 14 类可执行缺陷**：择优取向 / 第二相 / 非晶表层 / 仪器伪影**不属缺陷**，
其判据与处置**只在 §6 主表**（失败四分类），本表**不列、不指向** —— 避免 AI 在本表里读到"非缺陷"而分心。

## 位点·占位

### D-01 空位（vacancy / 缺位）
- **structural_form**：降低该位点占位（`occ` 由 1 起放开精修）
- **xrd_signature**：同族强峰的**强度比整体偏低**；差值图多个 hkl **同向偏移**；晶胞常略收缩
- **judge**：LS 把占位**推回 ≈1 ⇒ 无空位；稳定 <1 ⇒ 有空位**；占位与 Uiso 强相关，须交替验证
- **params_backend**：`occ`（**OCC 可用手动引擎**）；若与劈裂/耦合相关 ⇒ **GSAS**
- **pitfall**：**占位"假收益"**（全放开靠压低占位换 R）；`occ` 与 Uiso/背景相互补偿
- **example**：SampleA N6 = 0.9495（氮空位）

### D-02 反位（antisite）
- **structural_form**：在 A 位加一行 B 元素（或反之），两行占位**守恒**（Σ = 原位占位）
- **xrd_signature**：**有序度下降 ⇒ 超结构峰/特定 hkl 强度反转**；轻元素反位对 X 射线不敏感，常只体现在差值图
- **judge**：**占位守恒约束**下精修（`conserve_afrac` / `equiv_afrac`）；**自由精修把反位推向 0 不得判"无反位"**
- **params_backend**：**GSAS（复杂缺陷）** + 守恒约束
- **pitfall**：手动引擎做反位 ⇒ 结论不可信（见 `xrd-refinement` §4.5.1）；无约束自由精修把反位推向 0
- **example**：SampleA 参照 `Fe1-N` / `Fe2-N` 各 **0.25**；LiFePO4 Fe–Li 反位 0.0037

### D-03 混占 / 取代（mixed occupancy / substitution）
- **structural_form**：同一坐位多元素混占（GSAS 里同坐标多行）；或异价取代
- **xrd_signature**：峰强比随散射因子差变化；重/轻元素替换时**高角区强度**变化明显
- **judge**：混占比由 LS 定；元素对散射因子差小时**本征不敏感** ⇒ 必须与合成/EDS/XPS 等输入对照
- **params_backend**：GSAS（守恒/耦合）；**单纯 OCC 可手动引擎**
- **pitfall**：散射因子相近的元素对（Fe/Mn/Ni）**不可分辨**；把混占误判成"占位不足"

### D-04 间隙原子（interstitial）
- **structural_form**：新增一个原结构没有的位点（如 6b / 12c 空隙），占位起 0.05–0.2
- **xrd_signature**：出现**不能由原相解释的弱峰**（须与第二相区分）；差值图局部正残差
- **judge**：加位点后**残差峰是否被吃掉**（`R_before → R_after`）；占位是否稳定 >0 且**不撞界**
- **params_backend**：**GSAS**（额外物种）；手动引擎不得用于此判定
- **pitfall**：与"第二相弱峰"混淆；占位**撞上界（box-limited）**时的假改善

### D-05 额外物种（结晶水 / 羟基 / 碳酸根 / 溶剂）
- **structural_form**：加 O / H₂O / CO₃ 行（轻元素 X 射线弱）⇒ 常配 Uiso 固定
- **xrd_signature**：**低角背景抬升或宽包**；差值图低角宽残余
- **judge**：残差宽包是否被解释；与"非晶/表面层"区分（后者用**经验宽峰组分**，不写成结构位点）
- **params_backend**：**GSAS 优先**；手动引擎只能以经验宽峰近似
- **pitfall**：把非晶宽包硬写成水分子位点；轻元素**占位与 Uiso 无法同时定**

### D-06 有序-无序 / 超胞（cation ordering / superstructure）
- **structural_form**：建**超胞**或降对称性，把混占拆成有序子位点
- **xrd_signature**：**超结构弱峰**或消光规律改变；主峰轻微劈裂（对称性降低）
- **judge**：超结构峰是否**真实存在且被解释**（弱峰需**多峰共证**）；降对称后 R 是否**实质**改善
- **params_backend**：**GSAS**（换胞/换空间群，常伴 CIF 重建）
- **pitfall**：无超结构峰却强行降对称性 = **过拟合**；把峰形展宽当劈裂
- **⚠ reachability（可达性标记 · 起点依赖）**：本条**同因同果** —— 从**没有超胞的高对称 CIF** 出发，
  精修**到不了**有序超胞/有序化子位点（陷局部极小；且"换胞/降对称"这件事本身就要换出发点）。
  **强制动作**：只在一个 CIF 上试不出超结构/有序化时 ⇒ **不得判"无有序化"**，**也不得就此收尾**；
  必须**回到 §6.3 Ⅲ 的 ①【先穷举晶体族】②【再筛 2–3 个族 → 取/造对应 CIF 对比拟合】这一步**，
  **逐条确认该 CIF 筛选确实已经执行过**（穷举清单、筛查、排除理由都已落档；做法**沿用 §6.3 原文，本表不重抄**）。
  ⇒ **只有确认 CIF 筛选已执行**，才谈得上"无超结构 / 不可分辨"。

## 几何

### D-07 位点劈裂 / 静态位移（split site / static displacement）
- **structural_form**：一位点**拆两行**、坐标分开（劈裂距离**固定或自由**），占位常成对
- **xrd_signature**：高角峰的**选择性展宽/不对称**；特定 hkl 强度下降
- **judge**：**双方案并列**（见 `xrd-refinement` §4.5.2）—— (i) 自由精修看是否合并（**合并 = 本数据分辨不了**）；
  (ii) **几何取自出处、只精修占位**（出处给区间/多候选 ⇒ **至少试 2 个值**）
- **params_backend**：**GSAS**
- **pitfall**：**合并 ≠ 不存在**；**只用一个自定几何值就排除**（SampleA 试 1.2 Å ⇒ R 15.75 判"排除"，参照真几何 **1.502 Å**）
- **example**：SampleA K1a–K1b **1.502 Å** / K2a–K2b 0.495 Å，各占 **0.4983**

### D-08 偏心位移（off-center displacement）
- **structural_form**：原子沿特定方向**偏移**（不拆两行），常与有序性耦合
- **xrd_signature**：弱峰 + **键长异常**（须键长判据）
- **judge**：位移后**键长是否回到化学合理范围**；R 改善是否超过展宽改善的解释力
- **params_backend**：**GSAS**（坐标精修）
- **pitfall**：位移与 **Uiso 强相关**，容易互相补偿

### D-09 配位多面体畸变 / 倾斜（polyhedral distortion / tilt）
- **structural_form**：改 O 坐标（多面体倾斜/畸变），空间群常降低
- **xrd_signature**：峰劈裂 / 强度重排；低对称相的弱峰
- **judge**：与**更高对称模型**对比 R **与键长合理性**；不得只靠 R 判断
- **params_backend**：**GSAS**
- **pitfall**：高对称模型 R 常也"够好" ⇒ 误判"无畸变"
- **⚠ reachability（可达性标记 · 起点依赖）**：本条的**畸变/倾斜能不能被精修到，取决于 CIF 出发点** ——
  从**高对称 CIF** 出发常**到不了**低对称畸变（陷局部极小 / 坐标与占位耦合）。
  **强制动作**：只在一个 CIF 上试不出畸变时 ⇒ **不得判"无畸变"**，**也不得就此收尾**；
  必须**回到 §6.3 Ⅲ 的 ①【先穷举晶体族】②【再筛 2–3 个族 → 取/造对应 CIF 对比拟合】这一步**，
  **逐条确认该 CIF 筛选确实已经执行过**（穷举清单、筛查、排除理由都已落档；做法**沿用 §6.3 原文，本表不重抄**）。
  ⇒ **只有确认 CIF 筛选已执行**，才谈得上"这条维度在当前数据上不可分辨/不可达"。

## 扩展·微结构

### D-10 堆垛层错 / 位错（stacking fault / dislocation）
- **structural_form**：**不写进结构模型** —— 用**各向异性展宽**或经验宽峰组分近似
- **xrd_signature**：特定 **hkl 方向展宽**（hkl 依赖）、峰形**非高斯尾**
- **judge**：展宽的**方向依赖性**是否与层错模型一致；能否用第二相排除
- **params_backend**：GSAS 各向异性展宽 / 手动引擎经验宽峰
- **pitfall**：**归因错误**（层错 vs 尺寸/应变）；过度参数化

### D-11 微应变（microstrain）
- **structural_form**：不写结构；峰宽随 **tanθ** 增大
- **xrd_signature**：**高角峰展宽显著、低角窄**
- **judge**：与尺寸效应**分离**（Williamson-Hall 类，或 GSAS `Size`/`Mustrain` 联修）；**不得混报单一"尺寸"**
- **params_backend**：**GSAS**（支持分离）；手动引擎**不支持分离**
- **pitfall**：把应变当尺寸；未扣仪器展宽就报绝对值

### D-12 晶粒尺寸效应（crystallite size / 纳米展宽）
- **structural_form**：不写结构；FWHM ~ **1/cosθ**
- **xrd_signature**：**各角一致展宽、低角更明显**
- **judge**：与**仪器展宽分离**（必须扣仪器宽度，或用标样定仪器曲线）
- **params_backend**：GSAS `Size`；手动引擎只能给**表观值**
- **pitfall**：**表观值当真实尺寸**（未扣仪器展宽）；与应变混淆

### D-13 孪晶 / 共生（twinning / intergrowth）
- **structural_form**：加入孪晶域或共生相模型（结构级常需换相/超胞）
- **xrd_signature**：峰展宽/分裂不确定、强度比异常；无序共生 ⇒ **漫散**
- **judge**：**需要 TEM/文献支撑**；XRD 单独难以定论 ⇒ 标"**待定**"而非"适用"
- **params_backend**：GSAS（复杂）；常需多相模型
- **pitfall**：靠 XRD 单证据强行建模

### D-14 各向异性展宽（方向依赖的尺寸/应变）
- **structural_form**：不写结构；**按方向**给尺寸/应变
- **xrd_signature**：**只有特定 hkl 展宽**（如 00l 或 h00）
- **judge**：按向分解后 R 与**峰形**是否改善；与层错/劈裂区分
- **params_backend**：GSAS（各向异性 Mustrain/Size 模型）
- **pitfall**：被当成"**万能解释**"，掩盖真实缺陷（劈裂/层错）

## 尾注：三种「特殊情况」及其处理方式

> **定位**：**不是独立条目、不单列、不单独精修**；只在总表末尾作为**尾注**告诉 AI"**这些情形该按什么方式处理**"。
> **共同口径**：**这三种情形一律走 GSAS-II 判断**（与 `xrd-refinement` §4.5.1 一致 —— 涉及占位耦合/守恒/有序化，
> 手动引擎做不了这类判定）。
> **写法要求**：尾注里**只写"按什么方式处理"**（后端 + 对应条目的方案 + 该注意什么），**不重抄** D-01/D-02/D-03/D-06 的判据细节。

| 尾注 | 名称 | 归属条目 | **处理方式** |
|---|---|---|---|
| N-01 | **层间阳离子混排** | 归 **D-03 / D-02** | 在 **GSAS-II** 上按 **D-02 的占位守恒方案**（`conserve_afrac` / `equiv_afrac`）判断与精修；**不用手动引擎**（守恒耦合做不了） |
| N-02 | **氧空位有序化** | 归 **D-01 / D-06** | 在 **GSAS-II** 上先按 D-01 判空位，再按 **D-06** 看是否需要降对称/建超胞；空位成序常**必须换胞或降对称**才能表达 |
| N-03 | **非化学计量整比偏离** | 归 **D-01** | 在 **GSAS-II** 上判占位；**必须与合成/ICP/EDS 输入对照**，区分"真实非整比"与"占位假收益" |

## 每样品检查表如何引用本表

- **逐类判 适用 / 不适用 / 待定**，写进 `defect_table.json`（**10 字段以 §6.9 为准**）：
  `id` / `defect` / `source`（可选，但引用别人的**具体数值**必须标来源）/ `reported` /
  `verdict`（适用·不适用·待定）/ `reason`（**不适用也要写**）/ `backend` /
  `geometry_ref`（几何敏感维度必填） / `exec`（`R_before → R_after`） / `status`（未执行**必须写理由**）。
- **`id` 必须是本表里的 id**（或 `X-01`… 的表外假设）：机械自检（`integrity-check.mjs`）会核对；
  表外假设合法但**必须在报告里注明"表外假设"**。
- **排除某维度的唯一合法条件**（`verdict = 不适用`）：按该条的 `judge` 跑过、`reason` 已写、
  几何类维度**两方案齐全且 `geometry_ref` 有出处**、`exec` 数字齐全；否则只能写**待定**。
