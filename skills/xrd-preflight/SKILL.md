# XRD 前期工作流(阶段 1-3)

> 由 xrd-workflow 总 skill 加载。先读 workflow_state.json;完成后更新之。

## 阶段 1:材料识别与信息采集

**目标**:判断材料类型(A 高结晶主相 / B 结晶主相+杂质 / C 非晶低结晶主导)并锁定拟合目标。

1. 用户给了什么:样品体系、合成路线、相名/CIF、表征(XPS/EDS/NMR/EPR/IR)、数据文件/图。
2. 缺什么主动问(一次一组,不倾倒长问卷;答"不知道"即继续不阻塞):
   - 化学体系/合成路线(前驱体、温度)→ 定相先验、杂质推导
   - XPS/EDS/NMR/EPR 等(价态/元素/配位)→ 相鉴定判据
   - 理论或相关 CIF / ICSD / COD 卡片号
3. **C 类处理原则**:主体是非晶宽峰;若杂质峰不尖锐 → 直接拟合不单独问;
   尖锐或用户主动要求杂质处理 → 先询问杂质信息(可能组成/表征/副产物)再拟合;
   **信息不足不硬拟合**。
4. **A/B 类必问拟合目标**:晶胞/物相确认(轻量) | 结构精修(占位/坐标/B 因子,发表级)
   | 杂质定量/相分数 | 结晶度/晶粒尺寸。按目标决定精修路线。
5. 产出:material_class + goal_statement → 写入状态文件;必要时建 goal。
6. **结构来源（新）**——确认体系后用 `xrd_cif_edit` 把"已知结构"变成可精修模型：
   - `fetch_mp {chemsys}` / `fetch_cod {query, elements}`：从晶体库取候选 CIF（落到 `<out_dir>/ref/`）
   - **★ 高缺陷 / 掺杂晶体必做 —— 取多种晶型**：这类样品很难确定具体相类型，
     用 `polymorphs {formula|chemsys, max, per_polymorph}` 取回**多种不同晶型**的 CIF
     （按 (化学式, 空间群) 分组，每组返回最稳定的一个代表；实测 LiFePO4 从 70 个候选分出 26 种结构类型）。
     这一步是**必须做的**（用户 2026-09-18 原话："这个是要确定的"），不是可选。
     候选不靠理论打分裁定 —— 交给阶段 4 的 **`xrd_refine_auto`（fp2k）实跑 R 值裁决**。
   - 文献给了空间群+晶胞+位点 → `build` 直接造 CIF；已有 CIF 想核对 → `read` 输出结构表
   - **★ 晶体库与文献检索都失败时 —— 专业化构建 + 体检（必做，不能手写凑）**：
     复杂材料（掺杂 / 高缺陷 / 新相）常常在 MP、COD 里都查不到，只能从文献抄空间群与晶胞。
     这种时候**不要**凭坐标手敲 CIF —— 用 `xrd_cif_edit` 的两个专业动作：
     1) `build_orbit {spacegroup, cell, sites}` —— 每个位点只给**一个 Wyckoff 代表点**
        （文献报的 x,y,z）+ 占位；空间群自身轨道负责展开其余等价位置，输出**非对称单元式 CIF**
        （代表点 + 完整对称操作块），并回报每个位点落到的 **Wyckoff 字母与多重度**
        （务必拿它与文献对照：例如某立方氧化物应为 8b/24d/48e，对不上就是抄错了）。
        空间群符号怎么写都行（`R -3 m`、`R-3m`、`P21/c` 都能解析）。
     2) `validate {cif}` —— 写完**必须**体检再送精修：它在**原始文本层**核对位点轨道大小、
        展开胞原子数与**最小原子间距**。手写 CIF 最典型的坏法是把特殊位置的小数点写偏，
        解析器会**默默造出多余原子**（实测 6c 位写成 x=0.04 → 生成 39 个原子、出现
        0.115 Å 的重叠）；`verdict=warn` 就是这种信号，看到就先改坐标，别送下去。
     **边界（必须向用户讲明）**：这道体检只保证"文件与它自己声明的对称性自洽"，
     **不能判断结构化学上对不对** —— 层间距写错的文件同样自洽。结构对不对**只能靠 R 值裁决**。
   - 同系样品的已知结构（如"去掉 Sb 的单斜相"）→ `edit_text`（保留对称块）或 `edit_structure`
   - **不做化学合理性校验**：荒谬候选也允许写出来，交给拟合判定；细节见 `xrd-tools` §2

## 阶段 2:数据初筛

1. **格式与合法性（优先 `xrd_data_io`）**：`head` 嗅格式 → `read` 报点数/范围/步长；
   厂商 raw（Rigaku `;RAW4.00` / `[Data]` 段）可直接读；下游要 GSAS/FullProf 格式时 `convert`
   （`twocol` / `fxye` / `dat`，后者可 `pad_lines` 补 FullProf 固定跳过的 6 行）。
   仍需检查：2θ 单调递增、强度非负、清洗标记。
   - **★ λ 来源对账（2026-10-03 新增，数据入口必做）**：用 `xrd_data_io` 的 **`header`** 把**导头原文**读出来
     （位置式，不做解释），再逐字段找 λ 线索。厂商头里常见的键：Rigaku RAW → `Anode=`、`Alpha1=`、`Alpha2=`、
     `AlphaRatio=`、`Monochromator=`、`WaveUnit=`，以及 `[RangeHeader]` 的 `ActuallyUsedLambda=`。
     **判读规则**：
     - **`Monochromator=0` ⇒ Kα2 未剥离**，此时 `ActuallyUsedLambda` 是 **Kα 平均**、**不是 Kα1** ——
       直接把它当单色 Kα1 传下去会引入系统偏差。
     - **一个项目可能有多种 Cu 口径**：实测同一批数据里 RAW `Alpha1=1.5406` / GSAS `INST_XRY.PRM 1.540500`
       / 实际用过的 pcr `1.540560`（后者是**我们自己转换器的默认值**，不是厂家值）。**以"用户给的那个输入"为准**。
     - **权威顺序（用户定）**：**测量数据 > 用户提供的其他输入 > 问用户**。**我们自己的上游产物从来不是权威**。
     - **单色还是双线不是选择题**：**实验室光管 ⇒ 双线**；**同步辐射 ⇒ 单线**。只有**数据与用户输入都没说**时
       才提问，选项＝**靶材** 或 **同步辐射**（无靶材、λ 自己填），并声明"**不回答就用引擎默认**"。
     - **不要在 `header`/`evidence` 里判 λ**（它们只给原文）；判定写在对话里，定完**显式传值**给下游四个入口，
       并按 `xrd-workflow` 记进 `workflow_state.json` 的 `inputs` ＋ 一行 `journal.jsonl`。
2. **需要的预处理（同一工具）**：
   - 集流体/杂峰 → `cut` **数据级切峰**（`auto_al` 用常见 Al 箔峰位）；GSAS 脚本 mask 无效，只能这样切。
     **⛔ 切峰有门控（用户 2026-09-18）**：切峰**真实删除数据点**、改变全部下游数值，
     所以**只有在用户于对话中明确要求、且说明用途时**才启用 —— 调用必须带
     `confirm:true` + `reason:"<用途>"`，否则工具直接拒绝。声明用途仅限：①极片中 Al 箔/集流体峰；
     ②被无关伪影主导的区段。**禁止作为"预防性清理"顺手切**。
   - 峰形初值 → `fwhm`（给窗口列表；**≥3 个峰自动解 Caglioti U/V/W**，可直接喂给精修引擎）
   - 晶粒 / 相干尺寸与宽包尺寸 → `scherrer`（非晶主体的宽包与杂质尖峰用同一套口径读；未给仪器展宽时返回**表观值**，`corrected:false`）
   - 要送 fp2k → `align` 生成对齐的 `.dat`
3. **绘图（能力，不是工具）**：用**绘图能力**出全谱 2θ-I 图（低强度可加 log 或分段放大）。
   **首选本插件 `xrd_export_cif` 的 `data` 源**出图（顺带得到 `no_fit_model` 提示，无额外依赖）；
   否则用宿主可用的任意绘图能力（例如 python + matplotlib）。
4. **【视觉检测 V1】全谱读图定峰**（显式步骤；总表见 `xrd-workflow` §4，**不绑定具体视觉工具**）：
   出全谱 PNG 后**必须看图**回报：主峰位置/数量、宽峰 vs 尖峰形态、有无额外尖锐杂质峰、背底形态与抬升。
   读图通道按当前 agent 的**可用能力**三选一：①**agent 自带多模态 → 直接读图（优先）**；
   ②无原生视觉 → 走**宿主视觉桥**（若已安装，例如 `modlens_read_image` / dsh-office 的 `office_read_image`）；
   ③两者都没有 → **不得假装看过图**，明说缺视觉能力，把图路径交用户人工看或退回数值判据（峰位表 / FWHM 表）。
   机器找峰只粗定主峰，小峰后续核对。
5. 产出：peak_survey（主峰位置/状态/可疑峰记录）→ 状态文件 artifacts.peak_survey。

## 阶段 3:分相与定相

**C 类**（默认直接拟合，无需本阶段）：
- 无特殊要求或无尖锐杂质 → 跳过，去阶段 4 拟合主体宽峰。
- 需要尖锐杂质定量或用户要求筛选 → 按下面的配方走。

**★ 配方：非晶主体 + 晶态杂质**（配方由一次真实非晶体系工作实例抽象而成；
用户 2026-09-21 定"谢乐公式对非晶体 XRD 谱线分析与杂质尺寸判别很重要"。
**写法必须保持泛化：不带样品名、样品编号与该样品的科学数字**）

1. **建主体**：非晶 / 乱层主体的宽包（乱层碳典型为 (002)/(100) 两个宽包）用 `xrd_refine_manual` 的
   `extras`（经验宽峰 `{center,H,amp,eta}`）叠加默认背景建模；初值**先实测**宽峰位置与半宽
   （`xrd_data_io` 的 `fwhm` 给窗口即可），不凭经验猜。
2. **剥主体看残差**：主体拟合后残差里的尖峰才是杂质候选 —— `xrd_phase_screen` 的 `peaks`（还没有模型时）
   或 `residuals`（已有收敛工程时）取峰。
3. **定相必须全谱一致性**：`xrd_phase_screen` 的打分排序是**假设证据、不是结论**；
   **禁止只看目标峰位命中就定相** —— 实测出现过"目标峰位全部命中、全谱对照却失败"的假相。
4. **杂质相要用真 CIF**：`xrd_cif_edit` 取（`fetch_mp` / `fetch_cod` / `polymorphs` / `build_orbit`），
   让峰位由结构因子算出来。**不要手写 Bragg 峰位约束** —— 那是拿不到 CIF 时的替代品，有 CIF 就该用 CIF。
5. **尺寸判别用谢乐**：`xrd_data_io` 的 `scherrer`（参数见 `xrd-tools` §1）。主体宽包与杂质尖峰
   **用同一套口径**读才能互相比较；返回里 `corrected:false` 即**表观值**（未扣仪器展宽），转述时必须带上。
6. **定量口径要说清**：峰面积占比是**半定量**（未除 RIR / 密度 / 吸收），报告里必须标注；
   要定量走 GSAS 相分数。信息不足不硬拟合 → 输出已剥出杂质峰的 d 值表 + 建议表征手段。

**本配方已知的坑**（可泛化，均为实测教训）：
- **数据步长必须精确匹配**：下游按步长算位置，步长写错（如 0.0214 写成 0.021429）会让峰位整体错位。
- **XPS 只定性**：XPS 表面敏感、XRD 是体相，**不能用 XPS 占比推 XRD 峰强顺序**。
- **弱峰会被邻近或同源强峰淹没**：宽窗里"多出来的峰"可能只是强峰尾巴或同源峰 —— 先对理论相对强度再下结论。

**A/B 类**：
- 有很准信息（用户 CIF/明确相名） → 直接验证：理论峰对照主峰，全过 → 进阶段 4。
- 有体系线索 → ①AI 提议可能晶体族（按元素/体系先验；如 Fe/Mn/CN → 面心立方族），
  用户确认 → ②**取候选**：`xrd_phase_screen` 的 `fetch`（MP `chemsys` / COD `query`+`elements`），
  或 `xrd_cif_edit` 的 `fetch_mp`/`fetch_cod` → ③**打分排序**：`xrd_phase_screen` 的
  - 已有收敛工程 → 先 `residuals` 取 obs−calc 残余峰，再 `screen`；
  - 还没有模型 → `peaks` 从原始谱拾峰，再 `screen`
  输出「候选 × 命中残余峰数 × 加权分」排序表 → ④top-N 给用户确认。
- 完全无信息 → **不自动硬猜**：输出主峰 d 值表 + 建议表征手段，停下等线索。

**判读纪律（实测得出）**：打分排名是**假设证据**，不是结论 —— 理论峰匹配最好 ≠ 两相精修能收敛
（示例体系案里得分最高的候选恰是精修发散的那个）。选定与否最终由**精修**判定。

**★ 候选筛选是两级漏斗（用户 2026-09-18 定）**：
1. **宽进** —— `xrd_phase_screen`：残余峰 → 理论谱打分 → 候选列表（这一级只负责"筛"，可以宽松）。
2. **严出** —— **fp2k 实跑裁决**（`xrd_refine_auto`）：候选逐个 `cif_to_pcr` → `xrd_refine_auto` 实跑 → **比 R 值**。
   打分只能筛，**裁决必须实跑**；多候选时的实跑裁决正是 FullProf(fp2k) 优先于手动引擎的原因之一。

**高缺陷 / 掺杂晶体**：相类型本来就难定，**必须**先用 `xrd_cif_edit` 的 `polymorphs` 取回
**多种不同晶型**（见阶段 1 §6），再按上面两级漏斗逐个实跑裁定，不得凭一个猜测的结构硬拟合。

**【视觉检测 V2】峰归属核对**（显式步骤；总表见 `xrd-workflow` §4，**不绑定具体视觉工具**）：
把实测谱与候选相的理论峰位画成对照图（ticks）后**看图**核对 —— 主峰是否都被解释、有无系统偏移、
残余峰聚集在哪一相。读图通道同 V1：①agent 自带多模态→直接读图（优先）；②→宿主视觉桥（若已安装）；
③都没有→**不得假装看过**，明说并退回峰位表对照。

**判定门**：
- 候选相必须能解释全部主峰；与合成化学合理性冲突者剔除。
- 每排除/选定一相记录理由（状态文件 decisions）。
- 选定后按需用 `xrd_cif_edit` 改造（元素替换 / 占位 / 晶胞 / 去杂质元素），再进阶段 4。

产出：主相 CIF 或名义结构 + phase_summary.json（晶体族→卡片→评分→选定/排除理由）。
